## Implementation
- Standard IIO proximity channel with raw ADC reading (registers 0x11/0x12).
- Threshold events (rising/falling) using registers 0x06-0x09.
- Registers 0x00/0x01/0x03/0x04/0x05/0x15/0x16 programmed from board DTS.
- Software reset (0x80), PID sanity check (0x3e).
- Optional `vdd`/`vled` regulators and `vled` GPIO.
- IRQ handler reads/clears FLAG, compares raw value to thresholds, pushes
  IIO threshold events.
- Suspend/resume through the IIO core; sensor is powered down when disabled.
