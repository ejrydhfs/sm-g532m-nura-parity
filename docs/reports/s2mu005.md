# S2MU005 charger / MUIC / fuel-gauge parity report

## Files changed
- `drivers/power/supply/s2mu005-battery.c`

Patch: `$M/patches/s2mu005.patch`

## Evidence
- Downstream: `drivers/battery_v2/{s2mu005_charger.c,s2mu005_fuelgauge.c,sm5701_charger.c}`,
  `drivers/battery/*`, `drivers/muic/{s2mu005-muic.c,sm5504.c,muic-core.c}`,
  `drivers/mfd/{s2mu005_core.c,sm5701_core.c}`, `drivers/leds/leds_s2mu005.c`.
- Board DTS: downstream `mt6737t_grandpplte_ltn_open_01.dts` puts the S2MU005 MFD at
  I2C1 address `0x3d`, IRQ GPIO 81, edge falling.
- ROM symbols: `s2mu005_charger_probe`, `s2mu005_muic_probe`, `s2mu005_fuelgauge_probe`,
  `SM5701_charger_probe`, `sm5504_muic_probe`; ROM disassembly used for the enable/init
  sequence and fuel-gauge suspend.

## Parity implemented
- Standard `power_supply` charger driver with:
  - charger detection / enable / disable,
  - constant-charge voltage and input current limits,
  - charge behaviour and USB type reporting,
  - EOC dual-path and always-enable DT options,
  - suspend/resume and wakeup-source,
  - MUIC attach/detach, USB/OTG routing and accessory detection,
  - S2MU005 revision/register init matching the downstream sequence.
- Fuel-gauge driver extended with downstream init/shutdown and cross-driver register writes.
- SM5504/SM5701 remain explicit board variants; no silent hard-coding of one chip.

## Compile
```
make ARCH=arm64 LLVM=1 ... -j2 \
  drivers/power/supply/s2mu005-battery.o \
  drivers/power/supply/s2mu005-charger.o
```
Result: both objects compile cleanly (exit 0).

## DTS fragment (applied to integration)
```dts
&i2c1 {
	s2mu005-charger@3d {
		compatible = "samsung,s2mu005-charger";
		reg = <0x3d>;
		interrupt-parent = <&pio>;
		interrupts = <81 IRQ_TYPE_EDGE_FALLING>;
		pinctrl-names = "default";
		pinctrl-0 = <&s2mu005_chg_default>;
		wakeup-source;
	};
};

&pio {
	s2mu005_chg_default: s2mu005-chg-default-pins {
		pins-irq {
			pinmux = <PINMUX_GPIO81__FUNC_GPIO81>;
			input-enable;
		};
	};
};
```
